# CampusNotes

CampusNotes is a simple text-based project for organizing academic notes and assignments.

## Files

- `dsa.txt` - Data Structures and Algorithms notes.
- `maths.txt` - Mathematics notes.
- `reminders.txt` - List of reminders and pending tasks.
- `vcs.txt` - Version Control System notes.
- `study-plan.txt` - Weekly study plan.

## Usage

Open the relevant text file in any text editor to read or update its contents.

New notes and reminders can be added directly to their respective files.
